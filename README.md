# Web Refresher: BrewCraft Landing Page

It is a responsive and single-page product showcase for a cold-brew coffee concentrate. It has been built using semantic HTML5, custom CSS (Flexbox and Grid) and vanilla JavaScript.

## Features
- **Semantic HTML5:** It is organised with `<header>`, `<nav>`, `<main>`, `<section>` and `<footer>` elements.
- **Responsive Layout:** There is the use of mobile-first approach using Flexbox and CSS Grid also enhanced by a media query for desktop screens.
- **Interactive Calculator:** Vanilla JavaScript DOM manipulation will calculate concentrate and liquid ratios as per user-selected cup quantities.



## Reflection

The page is structured using semantic HTML5 tags and styling the navigation and hero section with Flexbox was straightforward due to this.

The more challenging aspect was refining the responsive behavior between mobile and desktop viewports, specifically to have proper alignment for the CSS Grid card layout and coordinate slider event listeners for DOM updates without console warnings.

During Web Development II, the main skill I want to improve is writing modular and scalable JavaScript along with improving my understanding of modern state management before going for React frameworks.
